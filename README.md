# Online-CV — öffentliche Website (November 2026)

Kompakter digitaler Lebenslauf mit Projektkarussell und vergrößerbaren Projektbildern.

## Datenschutz
Dieses Repository ist öffentlich. **Keine privaten Lebensläufe, Zeugnisse, Anschriften, Telefonnummern oder andere vertrauliche Dateien hier ablegen.** Die persönliche Bewerbungs-PDF bleibt separat und wird nur direkt an Arbeitgeber versendet.

## Start
`index.html` im Browser öffnen oder die Website über GitHub Pages bereitstellen. HTML, CSS und JavaScript benötigen keinen Build-Prozess.

## Projektbilder
Die Bilder sind in `assets/projects/<projekt>/` gespeichert. Die Bildpfade und die Bildbeschriftungen stehen in `projects.js`; dort lassen sich die Screenshots ändern. Die Fotos wurden für schnellere Ladezeiten als WebP optimiert. Zum Austauschen neue Bilder im WebP-Format speichern oder `src` in `projects.js` anpassen. Bereits eingefügte Originalbilder sind erhalten. Ein Platzhalter wird gezeigt, wenn noch keine öffentlichen Bilder verfügbar sind.

## Seitennavigation
Das Projektkarussell kann mit Maus, Pfeiltasten oder Touch bedient werden. Klick auf eine Projektkarte öffnet ein Detailfenster mit Bildern. Klick auf das Bild öffnet die vergrößerte Ansicht.

## Sprachen
Derzeit Deutsch; Englisch wird später ergänzt.
